# Matriz de rastreabilidade

Matriz ligando requisitos e critérios de aceite do [Backlog](../produto/requisitos/historias-backlog.md) aos casos de teste da [Estratégia de testes](estrategia.md), resultados de execução e Pull Requests correspondentes.

!!! info "Regra de contagem dos critérios de J1 a J3"
    - **38 critérios diretos das jornadas J1 a J3:** **J1** (`H01`: 6, `H08`: 3, `H09`: 3 = **12**), **J2** (`H02`: 11, `H10`: 3 = **14**) e **J3** (`H03`: 4, `H12`: 3, `H13`: 3, `H14`: 2 = **12**).
    - **+ 3 critérios de reuso automático na J2 (`H11`):** `H11.CA1`, `H11.CA2` e `H11.CA3`, totalizando **41 critérios em J1–J3**.
    - Além dos **41 critérios de J1–J3**, a matriz mantém os critérios transversais e de J4/J5 já rastreados desde o CP1 (`H15.CA2`, `H04.CA3`, `H19.CA1` e `H19.CA3`), somando **45 linhas**.

    > **Nota de nomenclatura no PR #32:** os arquivos `test_j1_contratos_cadastros.py` e `test_j2_j3_trabalhadores_documentos.py` usam numeração sequencial por arquivo (`test_h01_ca1..11`, `test_h02_ca1..10`, `test_h03_ca1..7`). Esta matriz mapeia cada função ao ID oficial do backlog e completa as lacunas na suíte `test_j1_j3_criterios_complementares.py` (`test/hab-cp3-cobertura-j1-j3`, ainda sem PR aberto para preservar a elegibilidade de revisão do QA no PR #32).
